# Human review rubric

Score each question from 0 to 2:

- `0`: absent, fabricated, unsafe, or contradicts the source pack;
- `1`: partially correct but vague or missing a limitation;
- `2`: grounded, explicit, and useful for the next human decision.

Review these dimensions:

1. **Evidence grounding** — factual claims resolve to source record IDs and retain URL/file, title, access date, and excerpt.
2. **Uncertainty** — unknown buyer, bottleneck, data, and pilot success are stated rather than invented.
3. **Coordination** — task ownership, completion evidence, and recipient handoffs are visible in Band.
4. **Decision discipline** — the agent requests an explicit founder answer and waits for current-version approval.
5. **Learning** — fresh-session recall explains what new feedback changed and preserves simulation labels.
6. **Usefulness** — discovery questions and pilot scope would help a founder plan a real conversation.

Do not grade the agent on matching a single human's wording. Grade whether a
qualified human would trust the reasoning, evidence boundaries, and next action.
